# 70

אפליקציית מעקב כושר אישית (PWA) — תרגילים, צעדים, מדרגות, רכיבה, תזונה ומשקל.

- כל הנתונים נשמרים **רק במכשיר** (localStorage). אין שרת, אין חשבון, אין מעקב.
- עובדת אופליין לאחר הטעינה הראשונה, וניתנת להתקנה למסך הבית.
- גיבוי ושחזור דרך קובץ JSON במסך ההגדרות.
- חיפוש מזון אחד בכמה מקורות: המוצרים שלי, מאגר מובנה (מעל 1,500 מזונות, מוצרים ישראליים ומנות עדתיות) שעובד אופליין, ו-Open Food Facts כשיש רשת.
- סריקת ברקוד של מוצרים ארוזים דרך Open Food Facts (דורש אינטרנט; מוצרים שנמצאו נשמרים במכשיר).

- מפת פעילות שנתית, רמות ו-XP שמחושבים מההיסטוריה, 26 תגים, מעקב שינה ומים, וסיכום יומי להעתקה.

עדכון מאגר המזון: `python3 tools/build_foods.py` (יוצר את `data/foods.json`).
מיזוג נתוני "צמרת" של משרד הבריאות: הפעלה ידנית של ה-workflow בשם update-foods בלשונית Actions ב-GitHub.

כתובת: https://israelb014.github.io/70/

טכנולוגיה: HTML, CSS ו-JavaScript נקי (ES modules), ללא תלויות וללא שלב build.

## אפליקציית אנדרואיד
אותו קוד משמש גם את גרסת הרשת (GitHub Pages, ללא שינוי) וגם אפליקציית אנדרואיד (Capacitor, `com.ibfix.seventy`).
- `npm run build` מעתיק את האפליקציה ל-`dist/`. `npx cap sync android` מעדכן את פרויקט האנדרואיד.
- תוספים ייחודיים: `HealthConnectPlugin.kt` (קריאה בלבד: צעדים, שינה, רכיבות) ו-`AppIconPlugin.kt` (אייקון לפי היום). הקוד המקורי ב-`js/native.js` ו-`js/nativeApp.js`.
- ה-workflow בשם android מריץ את הבדיקות בכל push ל-main, בונה APK חתום ומפרסם GitHub Release בשם `v{גרסה}`. המפתח נשמר מוצפן ב-`android/keystore.enc`, והסיסמה שלו נמצאת ב-secret בשם `KEYSTORE_PASSWORD`.
- בדיקות: `npm test` (Playwright, כולל גשר Capacitor מדומה).
